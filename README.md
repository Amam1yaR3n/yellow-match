# 黄色连连看

一款使用 Vite + TypeScript 实现的离线连连看战斗游戏。棋盘从7×7逐步扩展至10×10，玩家通过消除角色组建黄色战队，反复击败会复活的大魔王并获得炸弹。

## 运行与构建

```bash
pnpm install
pnpm dev
pnpm typecheck
pnpm build
pnpm package:toy
```

生产构建输出到 `dist/`，入口为 `dist/index.html`；JavaScript、CSS、全部角色图片与音效位于 `dist/assets/`，并通过相对路径引用，可部署在 `/toy/<slug>/` 子路径下。

`pnpm package:toy` 会重新执行生产构建、检查入口及资源路径，然后按上海时区当天日期生成可直接上传到哔哩哔哩 Toy 平台的 `yellow-match-MMDD-1.zip`。同一天重复执行会覆盖当天第一版；压缩包根目录为 `index.html` 和 `assets/`，不包含源码或开发文件。

项目遵循 `AGENTS.md`：不提供 `test` 命令，不包含或运行任何自动化测试。游戏试玩、规则验收、兼容性检查和回归验证由用户完成。

## 游戏规则

- 每次打开或刷新页面优先恢复本地存档。棋盘依次为7×7、8×8、9×9、10×10，之后每次清盘都生成新的10×10棋盘；队伍、等级、炸弹、大魔王生命与战斗计时跨棋盘保留。7×7和9×9固定中心为空，分别放48和80枚棋子；该空位可供连线路径通过，也可作为炸弹落点。
- 四个阶段每盘分别从现有17位角色中独立随机抽取9、12、15、17种，所选角色全部出现且数量均为偶数。配对数量尽量均分：7×7为6种各3对、3种各2对；8×8为8种各3对、4种各2对；9×9为10种各3对、5种各2对；10×10为16种各3对、1种各2对。额外配对随机分配，最终阶段包含全部角色。
- 新盘沿用完整可解的消除骨架，优先提供5组不同角色的开局组合，并优先保持同角色距离至少为3；约束无法满足时放宽距离，保留可解骨架。
- 两张相同卡片之间可用不超过两次转弯的水平／垂直路径连接时，即可消除；路径可绕到当前棋盘外围。
- 某角色首次消除一对时以Lv.1入队并获得一次首击，此后每对提升1级，等级没有上限。炸弹一次消除多对时按对数累计等级；首次入队仍只有一次Lv.1首击，遇到同批cut-in则延后至战场演出开始时结算。
- 战队成员每5级强化一次，强化次数 `R＝floor(等级÷5)`，伤害倍率为 `2^R`，没有四次上限；视觉进化阶段 `E＝min(4, R)`，仅Lv.5、10、15、20改变外观。Lv.25为32倍、Lv.30为64倍，此后继续翻倍，皇冠、标签配色和攻击特效固定四阶。
- 战队成员初始每2.7～3.3秒自动攻击一次；每5级将随机间隔上下限各缩短0.2秒，最多累计缩短2.4秒，Lv.60起固定为0.3～0.9秒。升级不改变当前已排定的普攻时点，新攻速从下一个攻击周期生效。普攻伤害为 `[10＋3×（等级−1）]×2^R`，Lv.5为44、Lv.20为1,072、Lv.25为2,624、Lv.30为6,208。Lv.1～4头像前冲；一阶发射飞行280ms的金色小飞弹，二阶起使用激光脉冲。普攻在发射时立即结算一次伤害，特效结束不再次扣血。
- 每盘某角色全部消除后释放一次大招，伤害为 `[560＋240×（等级−1）]×2^R`，按本次全部升级后的等级快照结算。Lv.5为3,040、Lv.20为81,920、Lv.25为202,240、Lv.30为481,280；普通、电击和冲撞大招共用此公式。
- 普通升级飘字显示实际普攻伤害增量；跨进化门槛时改为约0.82秒的“进化 II · 伤害×4”等累计倍率提示，同时皇冠局部提亮。同批升级只按最终阶段显示一次进化提示，支持炸弹跳级，四阶后不再触发进化提示，每5级强化及普通升级均沿用实际普攻伤害增量飘字。
- 首只大魔王有20,000血且不会反击。每损失当前生命上限的5%便排队随机消除一组当前可连接棋子，一次伤害跨过多个5%档位时逐档累计，降至0血也计入第20次。自动消除完整获得入队、升级、战斗力和大招收益，新增伤害可以继续触发消除。
- 自动消除只在前台且棋盘可结算时逐对播放并显示合法连接线，剩余待办不超过5、6～20、超过20时分别间隔350、200、100ms；待办期间棋盘锁定，但普攻、DPS与有效时间继续。待办可跨复活、演出、洗牌、换盘和刷新保存，不在旧存档中追溯补发。
- 每次击杀获得1颗炸弹，播放约0.9秒死亡演出，随后将上次最大血量乘2，再按新上限满血复活：20,000→40,000→80,000→160,000……没有胜利终局、倒计时或失败条件。生命、伤害与累计实际伤害使用大整数计算。
- 死亡演出期间冻结棋盘操作、攻击、其他战场演出和有效计时。致命一击的过量伤害舍弃；其他尚未命中的独立攻击保留，复活后继续命中，包括同一帧中尚未处理的攻击。
- 手动提示基础开局3次，三连开发视频后为6次；每次清盘进入新棋盘增加3次，剩余库存跨棋盘累积保留，不设玩法上限；成功找到可连接配对后使用一次扣除1次，洗牌和恢复存档不额外补充。玩家每3次成功普通消除会额外获得一次不扣库存的随机提示；相邻成功消除须相隔不超过2.8秒有效时间，只有选到不同角色或不可连接的第二枚棋子才会清零连击。同格取消、手动提示、炸弹和Boss自动消除不累计也不中断，提示会等待自动消除与换盘结束后在稳定棋盘显示。无可连接配对时自动洗牌，保留现有空位与剩余角色数量，并按可解骨架重新排列。
- 战斗力等于所有队员等级之和，也就是本局成功消除的配对总数，包含炸弹收益。DPS为跨历次大魔王累计实际伤害除以有效游戏秒数，排除溢出伤害；有效时间排除加载、cut-in准备和播放、复活冻结、系统休眠及页面冻结，包含战场演出与正常后台挂机时间。DPS默认保留一位小数，开局为0.0，刷新续玩保留战斗力和累计统计。

## 炸弹与大招演出

- 炸弹按钮位于提示按钮右侧。基础开局1颗，关注作者后为2颗；每次击杀增加1颗，无库存上限，跨棋盘保留；选中有效落点后才扣除1颗。
- 点击炸弹进入选点模式，点选落点直接引爆，不提前显示爆炸范围、补消位置或爆心。可选空格；中心及上下左右组成十字范围，越界和空格跳过，完全没有命中时不消耗并继续选点。
- 十字范围内某角色被命中奇数个时，从范围外补消一个同角色棋子。比较候选格到范围内该角色各格的最短横竖格数，距离相同按从上到下、从左到右选择，不要求能连线。补消不会再次扩散，整批移除保持各角色数量为偶数。
- 炸弹消除完整获得入队、升级、战斗力及清空角色的大招收益，同角色在本次消除中只触发一次大招。被消棋子按角色和行列顺序稳定两两配对，同时显示允许穿过其他棋子的蓝色直角视觉连接线。
- 默认开启必杀特写；同时触发多个大招时，按战队入队顺序连续播完所有角色cut-in，再同时开始整批战场演出。每段正常cut-in为1.1秒，包括160ms入场、800ms停留、140ms退场；最多250ms的图片准备等待单独计算。准备和播放期间冻结棋盘、提示、炸弹、普攻、旧战场演出及有效计时。
- 在设置中关闭必杀特写后，新触发的整批大招跳过图片准备、cut-in、起手音和角色专属音效：普通大招立即命中，皮卡丘与雷伊仍保留0.4秒电击命中与战场效果，冲撞角色仍保留1秒战场演出并在0.74秒命中。若关闭时当前段已经准备或播放，该段完整结束，再跳过本批剩余段；整批大招仍只登记一次。重新开启后，后续批次恢复完整演出。
- 战场演出开始后恢复棋盘、普攻和有效计时；普通角色立即结算伤害，皮卡丘与雷伊用0.4秒移至中央、放电1秒、0.4秒返回。Smiley、无敌少侠、奶龙、美团和大黄鸭用0.4秒扇形移至中央，蓄力0.12秒后冲刺0.22秒命中，再反弹淡出0.26秒；同批冲撞同时开始并共同汇聚至Boss。整批演出登记后才检查清盘或死局，遇到复活冻结则延后处理；已命中的冲撞照常退场，未命中的冲撞在Boss前等待复活后续撞。
- 新cut-in会暂停旧电击、冲撞及其待命中时间，横幅结束后继续；换棋盘保留战场演出。复活不会取消尚未命中的大招。

- Among Us「我是狼」沿用横幅后进入1.5秒持刀演出：头像用0.4秒放大移至战场中央，0.25秒生成银刃深柄卡通短刀，带刀冲刺0.25秒，在0.9秒刀尖接触魔王时结算一次原有大招伤害；红白闪光停留0.15秒后，用0.45秒带刀缩回原位并淡出，不显示血液。复用冲撞的暂停、复活等待、存档恢复与预览流程，减少动态效果时使用静态呈现。

## 操作与无障碍

- 鼠标或触屏：按下即选择卡片或炸弹落点，不等待松开。普通消除立即提交逻辑，退场动画独立收尾。
- 键盘：Tab进入棋盘，方向键移动，Enter或空格选择。炸弹模式可以移动到空格；再次点击炸弹按钮或按Esc取消，库存不消耗。
- 炸弹选点期间战斗继续，提示按钮禁用，只保留炸弹按钮选中态和标准棋盘焦点环。复活与cut-in时冻结选点；Boss自动消除不会取消炸弹模式或消耗库存。
- 排行榜、设置、互动入口在PC和手机竖屏端沿战场HUD宽度左、中、右均布；手机横屏端在棋盘右侧纵向排列。三个入口沿用相同的加载、会话占用和生命周期禁用状态，弹窗打开期间战斗继续。
- 设置弹窗提供0–100全局音量、必杀特写开关和“重置存档”；互动弹窗提供作者资料与主页跳转、开发记录 `BV19R8i6KEaP` 的本地封面及观看入口；互动奖励仅保留标题和两张礼盒卡片，文案为“一键三连获取提示✖️3”“关注获取炸弹✖️1”，自动查询和防重复发放逻辑保持不变。左右两栏等高，弹窗按内容收紧。PC和手机横屏为左右两栏，手机竖屏为单列滚动。
- 页面隐藏或失焦后战斗继续，后台静音并停止旧声音；返回后只呈现当前演出、播放新声音，没有失焦暂停或继续按钮。正常后台计时延迟按攻击、电击、冲撞命中与复活事件的顺序补推进，不重放积压特效。飞弹、激光、皇冠和标签动效仍随cut-in及复活冻结；换棋盘保留战场演出，重置存档清理旧局声音和视觉。
- 保留中文ARIA标签、状态播报、深蓝双环焦点、增强对比度和减少动态效果支持。棋盘尺寸及空格坐标随当前阶段更新。
- 减少动态效果时，cut-in、电击和冲撞使用0.3秒静态表现，关闭皇冠提亮和标签扫光；飞弹改为魔王处200ms静态闪点，激光保留阶段颜色和宽度并使用200ms静态反馈，爆炸也使用短暂静态反馈，棋子连接线静态显示约200ms。已结算的伤害不会重复结算。

普通消除、炸弹和Boss自动消除共用批量结算流程，先更新盘面与成长，再播放大招，最后只进行一次清盘或死局处理。棋盘生成和洗牌在独立Worker中计算；预生成缓存绑定下一阶段，不支持Worker时仅在需要棋盘时降级计算。Worker随生产构建输出为独立相对路径资源。DPS的时间刷新限制为每100ms一次，伤害发生时立即刷新。

## 本地续玩与后台挂机

- 本地存档按当前浏览器、站点与游戏部署路径隔离；Toy SDK 可用时同步当前账号的云存档，不提供手动导入导出。关闭、刷新、浏览器回收后重新打开只恢复保存状态，不补算离线收益。后台会推进已有队员的战斗并累计Boss掉血产生的自动消除待办，但不会在后台执行这类自动消除；返回前台后才逐项兑现。
- 关键消除、成长、命中、奖励和换盘事件同步提交后立即保存，其他计时进度每秒保存一次，隐藏、冻结和离开页面时也保存。保留上一份有效快照作为备份；主档无效则读取备份，均无效时提示并新开局。存储被禁用或空间不足时显示无法保存提示，仍可继续当前会话。
- 保存当前棋盘和空位、提示、炸弹、队伍等级和顺序、已排定普攻时间、魔王当前及最大生命、复活剩余时间、Boss自动消除待办、累计伤害与有效时间。大招准备预算、完整特写批次、电击与冲撞进度和命中标记、待命中队列、生成或洗牌待办也一并保存，恢复后按剩余计时继续，不重复结算伤害或奖励。选中框、三连进度、普通粒子和旧音频不恢复。
- 战斗时间独立于画面刷新。明确的页面冻结、离开页面、休眠或时钟跳变不补收益；未收到明确通知时，单次超过120秒的计时断档整段不计，其余正常延迟按事件补推进。该边界可能计入无法识别的短休眠，也可能少算极端后台限频，不能保证所有浏览器对休眠识别完全一致。
- 同一游戏地址只有一个页面运行和写档，后开的页面显示占用提示。原页面关闭后可点击“重新尝试进入”恢复最新存档。优先使用Web Locks；不支持时使用IndexedDB事务租约，异常关闭后租约最多125秒过期。
- 音量和必杀特写偏好使用独立、版本化且按当前部署路径隔离的本地设置记录，不写入游戏或云存档；无效设置回退为音量50、必杀特写开启。
- 设置中的“重置存档”需要确认，确认后清理旧局状态、任务、音频与存档备份，从7×7、20,000血魔王、0炸弹的新局开始；音量与必杀特写偏好保持不变。
- 数字达到一万亿时使用四位有效数字的科学计数法；空间不足时允许提前使用，并按实际可用宽度适度缩小字号。战斗力和DPS允许标签、尾数和指数分行，完整数值保留在标题提示中；格式化不影响大整数计算及存档精度。
- 普攻、大招和升级飘字在统一战场文字层呈现，按整个动画的缩放和漂移范围限制位置，为描边、阴影及圆角留出空间。空间不足时缩短移动距离，窗口尺寸、方向或字体变化后重新排布；减少动态效果时保持相同边界。数值不使用省略号或截断尾部。

## 视觉策略

- 17 个角色的运行时图片统一为 256px 透明 PNG，光学轮廓长边约占画布 84%，主黄色集中在 `#F9D23A` 附近并保留各自的高光和阴影。
- 所有卡片使用同一组 `#FFF0A8` 暖黄背景，角色边缘叠加细暖棕轮廓，使角色整体色相接近、仍可依靠造型公平辨认。
- 选中、键盘焦点和提示统一使用深蓝双环；提示只强调 1.5 秒，不显示连接路径。
